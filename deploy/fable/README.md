# Fable launch pack

Everything a strong-reasoning session needs, and nothing it doesn't. Committed
here because the live pack lives in `<AION_HOME>/FABLE/`, which is machine
state — it does not survive a rebuilt machine, and it cannot be read from a
phone. Regenerate the live copy any time with `aion fable-pack`; this is the
durable one.

## How to start the session

**If the session has the repository** (running in Claude Code, on this machine
or the permanent host) — this is the normal case:

1. Add **INR 700** of credit. That is the authorised tranche, not a target.
2. Switch the model to the strong one.
3. Send exactly this:

   > Read `deploy/fable/START_HERE.md` in full and begin. Everything you need is
   > in that one file — instructions, measured state, standing decisions, the
   > plan schema and the definition of done. Do not summarise it back to me.
   > Start with artifact 1.

`START_HERE.md` is generated by `aion fable-pack` from the same sources as every
other file here, so it cannot drift from them. One read gives the session
everything.

**If the session has no repository access** (a plain chat window): the repo is
private and cannot be fetched, so attach `START_HERE.md` to your first message
instead. Same file, same content.

## What to do with them

```bash
mkdir -p ~/lucyos/incoming
# save each artifact there, then:
aion plan check incoming/plan-<name>.json     # rejects any unverifiable step
aion plan apply incoming/plan-<name>.json     # queues it for the cheap loop
```

`plan check` is a real gate, not a formality — it refuses steps that lack a
`validation_command` or `success_criteria`. If it rejects the plan, that is the
strong model's error to fix, not something to work around.
