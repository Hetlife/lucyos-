# FM-08 — Isolate pre-commit Git environment
WHY
A hook-triggered test suite corrupted its parent index in an isolated worktree.
VERIFIED EVIDENCE
Actual attempted audit commit; before-fix hermetic regression fails twice with absolute GIT_INDEX_FILE; after-fix tests pass.
EXECUTOR
CODEX fallback, deterministic tests (Claude Code weekly limit).
CONTEXT PACKET
scripts/pre-commit; tests/test_authority_verifier.py; tests/test_precommit_isolation.py; 10_EXECUTION_RECEIPT.md.
SCOPE
Clear repository-local Git environment after resolving REPO; add two hermetic hook tests.
DO NOT TOUCH
User worktrees, global Git config, security/authority gates, production DB.
DEPENDENCIES
None. Required before publishing via affected hook.
STEPS
Preserve incident index/diff; reproduce in temp repository; clear variables enumerated by Git; test real commit behavior; run full hooked suite; explicit two-file staging.
ACCEPTANCE TESTS
Nested Git leaves parent tree/index unchanged; failed suite blocks commit; secret scan and full suite remain enforced.
ROLLBACK
Revert this two-file commit; retain preserved incident evidence. Do not use unsafe old hook for worktree commits.
DELIVERABLE
Scoped PR plus before/after and full suite evidence.
STOP/ESCALATE IF
Unexpected protected changes, test/environment mismatch or staged-file drift.
HIGH-MODEL REVIEW
YES, milestone review of corruption boundary; implementation bounded.
