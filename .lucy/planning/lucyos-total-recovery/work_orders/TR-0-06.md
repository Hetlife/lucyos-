# TR-0-06 — Archive tags and branch-delete script

**Why:** 127 remote branches; deletion from agent sessions returns 403; earlier lists misclassified (ISSUE-017). Tags make deletion lossless.
**Current evidence:** EV-BRANCHES, `evidence/branch_ledger_20260930.tsv`
**Executor:** CODEX (tags, script) + OWNER (delete)
**Scope:** `git tag archive/<branch-name-with-slashes-as-dashes> <tip>` for every branch not CONTAINED; push tags; `evidence/delete_branches_20260930.sh` (dry-run by default)
**Do not touch:** no branch deletion, no force-push, no merges
**Dependencies:** none

## Steps
1. Re-run `python3 scripts/branch_ledger.py > evidence/branch_ledger_<date>.tsv` on current main.
2. For every row with class != CONTAINED: create the tag at the tip and push tags (`git push origin --tags`).
3. Generate `delete_branches_<date>.sh` listing `git push origin --delete <branch>` for CONTAINED + PATCH_IN_BASE + the UNRELATED and SUPERSEDED/REJECT rows from `03_`; first line `set -e; [ "$1" = --yes ] || { echo dry-run; exit 0; }`.
4. Open a docs PR with the script and the refreshed ledger.

## Acceptance tests
- `git tag -l 'archive/*' | wc -l` equals the number of non-CONTAINED branches
- dry-run prints the list and exits 0

**Security / rollback:** tags are additive; script does nothing without `--yes`
**Deliverables:** tags on origin; script; PR
**Stop conditions:** 403 on tag push: report, owner pushes tags from Lucy-den
