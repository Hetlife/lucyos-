2. 3. Mark-2: same set plus `python3 scripts/verify_authority.py deploy`.
4. Pad: from Lucy-den, `ssh` per `docs/lucynest-resume-20260926.md` (branch) and run `lucynest_ctl.py info` only; record client PID, sha256 of deployed files, boot hook presence.
5. Write one JSON per host with the raw outputs (stdout captured) and a 10-line summary in `evidence/CENSUS_SUMMARY.md`: role, HEAD vs main, services active, executors present, OpenClaw state, backup age, drift, host clock skew, freeze evidence, pending firmware.
6. Update `EVIDENCE_INDEX.md` keys EV-LIVE-DEN, EV-LIVE-M2, EV-LIVE-PAD from 'secondhand' to 'observed <date>'.
