# TR-3-01 — WhatsApp via OpenClaw live from the phone

**Why:** The product's steering wheel is WhatsApp. Only the phone round trip proves L2 for the owner.
**Current evidence:** TR-1-05; D-3
**Executor:** OWNER + OPENCLAW
**Scope:** OpenClaw WhatsApp channel configuration on Lucy-den; `lucyos` skill enabled; evidence file
**Do not touch:** no LucyOS code; no Meta Cloud API setup (optional path)
**Dependencies:** TR-1-03 merged; TR-1-05 done

## Steps
1. Owner links the WhatsApp channel in OpenClaw (its own runbook).
2. OpenClaw routes owner messages that match the LucyOS grammar to `lucyosctl whatsapp` with `LUCYOS_PRINCIPAL` set to the sender id; anything else is normal OpenClaw conversation.
3. Owner sends `status`, `blockers`, `approve <ID>` from the phone; replies arrive in WhatsApp.
4. Record redacted transcript + `aion today` in `evidence/e2e_phone_<date>.md`.

## Acceptance tests
- approval decided from the phone; event has channel=openclaw and the principal
- `aion status` reply received on the phone within 10 s

**Security / rollback:** OpenClaw channel can be unlinked; LucyOS unchanged
**Deliverables:** evidence file; EV-L2-PHONE
**Stop conditions:** OpenClaw cannot set env for the skill: report to CLAUDE_CODE to accept `--principal` as an argument instead
**Fable review required?** NO
