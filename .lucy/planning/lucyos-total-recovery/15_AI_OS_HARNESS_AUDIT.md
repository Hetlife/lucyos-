## Mistakes found in this pass (added to `04_`)
- ISSUE-030: context compilation is a hard precondition for every task, including DET shell steps; a compiler or git failure blocks deterministic work that needs no context.
- ISSUE-031: `sessions` carries INR but not tokens or executor identity; cost-per-verified-task cannot be computed per executor.
- ISSUE-032: approvals bind task and title, not the exact action and parameters; a changed `exec_command` after approval would run under the same approval id (verify in TR-5-04; if `approvals.decide` re-checks the command, downgrade).
- ISSUE-033: four contract-skeleton modules are unreachable at runtime yet count as core surface (cleanup C-05).
