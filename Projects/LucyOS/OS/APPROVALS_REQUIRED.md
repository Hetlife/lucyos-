# Approval Register

No approval is currently required for the next local inspection/staging step.

Future approval gates:

- promoting staged SEVAA files over an existing project;
- installing system packages or changing system services;
- public deployment or creating external infrastructure;
- paid plans, paid APIs, advertising, or non-zero Apollo credits;
- Razorpay configuration beyond test-only preparation;
- public publishing or automated outreach;
- GitHub push, merge, or release.

When a gate is reached, record the exact action, impact, cost, rollback, and required
founder response here before asking.
